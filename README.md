# 📌 Description
**CS2 Killmage** is a fun little program I developed. There is no specific purpose of the program other then that every time you get a kill in CS2 and Random Image pops up in front of your screen. I created this program due to a small trend on Social Media.

## 🛠️ Installation
Download the latest release version of [CS2 Killmage.exe](https://github.com/Emco878/CS2-Killmage/releases/latest)

>⚠️ Note: This app is signed however SmartScreen may warn you as my reputation is low. The program is safe. The source code, can be found in `main.py` & `gui.py`

## ✨ Features
- Avatar Region
- Health Region
- Kill Feed Region
- Auto Pixel Adjustment per Resolution
- Color Tolerance Adjuster

## 📃 How-To-Use
- `image` + `settings.txt` + `sound.wav` must all be in a folder with `CS2 Killmage.exe` for the application to work.
- Put in any amount of images you want into the `image` folder
- Once you open the application select the Resolution you are using and click the `Save` Button
- If you get a kill and an `image` does not show up consistently make sure you adjust your `tolerance` value or adjust your `pixel location` in the 3 Regions


## 📦 Requirements
- Python 3.12 (Recommended)
